## Video #1: "Linux Commands You Actually Need as a Beginner"

### Production Checklist

**Before Recording:**
- [ ] Clean terminal, big font (16pt+), dark background
- [ ] Open a fresh directory with some sample files to play with
- [ ] Write your 12 commands on a notecard next to you
- [ ] Test mic one more time — record 10 seconds, play it back

**While Recording:**
- [ ] Go slower than feels natural. Beginners need time.
- [ ] Type the command, pause, explain what it does, then run it
- [ ] Show the output — don't just describe it
- [ ] If you mess up, keep rolling. Edit it out in Kdenlive.
