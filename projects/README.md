| ⭐⭐⭐⭐⭐ | Exceptional — production-ready, creative, well-documented |
| ⭐⭐⭐⭐ | Very good — works well, minor improvements needed |

| ⭐ | Poor — doesn't work or missing most requirements |

## How I'll Evaluate

When you complete a project, I'll:

1. **Read the code** — check quality, structure, best practices
2. **Run it** — verify it actually works
3. **Check requirements** — did you meet all of them?
4. **Assess creativity** — did you do something unexpected?
5. **Review documentation** — can someone else use it?
6. **Give honest feedback** — what's good, what needs work
7. **Suggest improvements** — specific, actionable next steps
